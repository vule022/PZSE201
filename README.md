# MediKarton

MediKarton je Java aplikacija razvijena u okviru predmeta SE201 – Softversko inženjerstvo.

Aplikacija omogućava upravljanje korisnicima, pacijentima, lekarima, zdravstvenim kartonima, pregledima, terminima i obaveštenjima. Projekat sadrži implementaciju poslovne logike, rad sa bazom podataka, bezbednosne provere i automatizovane JUnit testove.

## Pokretanje projekta

Za pokretanje aplikacije potreban je JDK 21.

```bash
./gradlew run
```

Za pokretanje automatizovanih testova i provere pokrivenosti koda:

```bash
./gradlew clean check

```
